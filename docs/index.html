mobile.de Sync

A dealer's vehicle inventory from the mobile.de Search API, in WordPress — synced, filterable and searchable, without a second plugin.

Download the plugin Source on GitHub

GPL-2.0-or-later · WordPress 5.8+ · PHP 7.0+ · custom post type fahrzeuge

What it does

Every run fetches only what changed. Once a day a full reconciliation follows, and only after one of those is a sold vehicle removed — to the trash, never into the void.

  • Filtering of its own

    Dropdowns, checkboxes, two-handle range sliders, search and eight sort orders over the fields the feed already fills. No FacetWP required.

  • Counts that mean something

    Every option says how many vehicles are behind it, counted against the rest of the selection — so an option that would leave nothing says so.

  • Works without JavaScript

    The filter bar is a plain GET form and the filters live in the URL, so a filtered list can be linked, bookmarked, paginated and cached.

  • An enquiry form

    Reaches the dealer by e-mail with the vehicle it is about, and is filed in the database as well — so a mail that fails is not simply gone.

  • Structured data

    A complete Car and Offer in JSON-LD, plus OpenGraph cards — suppressed when an SEO plugin already emits them.

  • It tells you when it stops

    A failed or overdue sync arrives by e-mail. Once per problem, not once per run, and the recovery is sent straight away.

Get it

Releases are built and published from the repository. The download below always points at the newest one.

2.2.0 Latest Filters · enquiries · structured data · alerts
  1. Download the ZIP and upload it under Plugins → Add New → Upload Plugin.
  2. Deactivate any other mobile.de plugin — two importers on one post type overwrite each other.
  3. Open Vehicles → Sync Settings and enter username, password and seller ID.
  4. Hit Test connection, then run the first import: wp wmds sync --full --all

Updates arrive through the WordPress updates screen like any other plugin — the release feed is the update channel, so there is nothing else to install.

In a template

The archive filters itself. Everywhere else, four shortcodes.

// The filter bar, on its own or beside a list
[vehicle-filter]
[vehicles filters="yes" pagination="yes" posts_per_page="12"]

// A plain grid, filtered by whatever meta key you name
[vehicles make="Audi" fuel="Diesel" columns="3"]

// How many the current filters leave, and an enquiry form
[vehicle-count]
[vehicle-enquiry]

What it needs

WordPress 5.8 or newer
PHP 7.0 or newer — CI checks 7.0, 7.4 and 8.3 on every push
Extensions json, curl or allow_url_fopen, and gd or imagick
Outbound access services.mobile.de
Credentials A mobile.de Search API user and the numeric seller ID
Optional WP-CLI for the first import, a real cron job instead of WP-Cron
